 Project Statement Problem Statement

College clubs often manage member and event information manually. A simple digital system can organize clubs, members, events, and registrations.

Objective

Build a basic Python College Club Management System using a terminal interface and local file storage.

Scope

Club management, member management, event management, and event registration.

 Target Users

Students and college club coordinators.

Limitations

The current version does not include online login, GUI, cloud storage, notifications, payments, or an external database.
